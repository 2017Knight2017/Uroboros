# Uroboros

This is my first ever mobile app, which I have 
developed for the Enactus Hackathon at 6-8 November 2026. 
It might be not very stable in some cases or not have
a lot of functionality, but it is certainly a pretty
complex Flutter project I had much fun working on.

Also I'm really impressed that I was able to 
finish a viable product with an unknown tech in 
just 14 hours (or two nights). It gives me back
the confidence in my learning skills.

## Tech Stack
Flutter with following libraries:
- *[image_picker](https://pub.dev/packages/image_picker)* for the camera integration.
- *[path_provider](https://pub.dev/packages/path_provider)* for getting the data directory on the device.
- *[geolocator](https://pub.dev/packages/geolocator)* and *[geocoding](https://pub.dev/packages/geocoding)* for location identification with GPS.
